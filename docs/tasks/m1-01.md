# M1-01: Runnable development scaffold

Status: ready to implement; stack not selected.

## Outcome

A contributor can clone SALTY, install documented prerequisites, start a local application, and run automated checks without institutional credentials or a particular AI tool.

## Inputs

Read [architecture](../architecture.md), [data contract](../data-contract.md), [security](../../SECURITY.md), and [contribution instructions](../../CONTRIBUTING.md). Existing Formation Pathways and other project code has not been reviewed in this repository; inspect it if made available, and record compatibility assumptions otherwise.

## Scope

- Compare a small number of suitable stacks and record an ADR selecting language/framework, relational storage, migrations, local file storage, and tests.
- Scaffold the application with pinned or locked dependencies and documented runtime versions.
- Provide install, start, check, and reset instructions, including effects of destructive local reset commands.
- Add a minimal health endpoint that exposes no configuration or secrets.
- Supply an example configuration containing placeholders only; no school credentials are required.
- Add CI appropriate to the actual scaffold and retain documentation checks.

## Acceptance criteria

- [ ] A fresh local checkout starts using only the documented prerequisites.
- [ ] Health check returns a defined success response.
- [ ] A clear error identifies missing local configuration without leaking secrets.
- [ ] Formatting/type/build/tests, as applicable to the selected stack, are documented and pass.
- [ ] Generated artifacts, secrets, and local data remain untracked.
- [ ] README describes the actual runnable state and remaining milestone work.

## Exclusions

School OAuth, live Canvas credentials, production hosting, a complete archive UI, and runtime AI-provider integration. Do not expand this task into the entire milestone.
